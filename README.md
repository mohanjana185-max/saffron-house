# Saffron House Restaurant Website

Responsive restaurant landing page made with plain HTML, CSS and JavaScript.

## Run
1. Extract `saffron_house_restaurant.zip`.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Internet connection is needed for Google Fonts and the remote food/restaurant photos.

## Features
- Responsive desktop/mobile layout and mobile navigation
- Animated hero background, marquee, reveal-on-scroll effects and hover/click feedback
- Menu category filters and demo cart
- Login / sign-up modal (front-end demo only)
- Reservation request form (front-end demo only)
- No frameworks or build tools required

## Customize
Edit restaurant address, phone, hours and menu content in `index.html`. Replace image URLs with your own photos if desired.
Login, reservations, and checkout are visual front-end demos: connect a secure backend before using them for real customers.
